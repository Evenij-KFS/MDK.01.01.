# Тема: "Введение в С++"
## "Язык программирования С++"
Язык программирования С++ представляет высокоуровневый компилируемый  язык программирования общего назначения со статической стилизацией.
Своими корнями он уходит в язык С который был разработан в 1969-1973 годах. В компании Bell Labs программистом Деннис Ритчи. 
В начале 80-х годов - программист Бьерн Страуструп работал в компании Bell Labs разработал С++, как расширение к языку С. Фактически в начале С++ просто дополнял С с некоторыми возможностями ООП. Изначально язык назывался 'Си с классами'
С++ является компилируемым языком - это значит что компилятор транслирует исходный код на С++ в исполняемый файл, который содержит набор машинных инструкций.
### Основные компиляторы.
- g++
-  clang
- Компилятор Microsoft VS
### Состав компилятора g++
- сpp - процессор
- as - ассемблер
- g++ - сам компилятор
- id - линкер
### Зачем нужно компилировать файл.
- Исходный С++ файл - это всего лишь код, но его невозможно запустить как программу или использовать как библиотеку, поэтому каждый исходный файл требуют скомпилировать в исполняемый.
### Этапы компиляции.
- Препроцессинг - это макропроцессор который преобразовывает программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными проектированиями.
***Например: Препроцессор добавляет хэдэры в код (# include), убирает комментарий.***<br>
- Компиляция преобразование в ассемблерный код. Это промежуточный шаг между высокоуровневым языком и машинным кодом.
- Ассемблирование - перевод ассемблерного кода в машинный.
- Объектный файл - это созданный ассемблером промежуточный файл хранящий кусок машинного кода.
***Этот кусок машинного кода, который не был еще связан с другими кусками машинного кода - называется объектным кодом.***<br>
- Компоновщик (линкер) - связывает все объектные айлы библиотеки в единый исполняемый файл который мы можем запустить.
- Загрузка.

#### Задание: Опишите структуру проекта С++ в VS объясните каждый файл в Visual Studio.

##### Ответ:

- В проекте VS есть два главных файла: sln — список проектов и настройки сборки, vcxproj — исходники и параметры компиляции. filters — для отображения папок в IDE, user — личные настройки, его не добавляют в Git.
- Папка «Внешние зависимости» виртуальная. В ней автоматически лежат заголовочные файлы h из подключенных библиотек, чтобы компилятор понимал код. Они только для чтения.
- При ручном подключении библиотек создают папку с include (заголовки), lib (статичные .lib для линковки) и bin (.dll для запуска).
- Пакетные менеджеры сами скачивают библиотеки по списку в файле и подключают их.
- Папки Debug, Release, .vs и user-файлы исключают из Git — там временные данные. В репозиторий кладут только исходники, sln и vcxproj.

# 5. Ход ферзя

Шахматный ферзь ходит на любое количество клеток по диагонали, горизонтали или вертикали. Даны две различные клетки на шахматной доске без фигур. Определите, может ли ферзь попасть с первой клетки на вторую одним ходом.

Формат ввода
Программа получает на вход четыре целых числа от 1 до 8. Первая пара чисел задаёт номер столбца и номер строки для первой клетки. Вторая пара чисел аналогично задаёт вторую клетку.

Формат вывода
Программа должна вывести YES, если из первой клетки ходом ферзя можно попасть во вторую, или NO в противном случае.

Пример 1:
Ввод
1
1
2
2

Вывод
YES

Пример 2:
Ввод
1
1
2
3

Вывод
NO


# 6. Прямоугольный треугольник

Напишите программу, которая проверяет, является ли треугольник прямоугольным.

Формат ввода
На стандартный поток ввода подаётся три целых положительных числа — стороны треугольника. Числа не превосходят 30000.

Если полученный треугольник является прямоугольным, напечатайте YES. Если треугольник не является прямоугольным, напечатайте NO. Если с заданными сторонами невозможно построить треугольник, напечатайте UNDEFINED.

Пример 1:
Ввод
2
3
5

Вывод
UNDEFINED

Пример 2:
Ввод
3
4
5

Вывод
YES


# 7. Високосный год

Определите, является ли год високосным по григорианскому календарю.

Напоминание:

- год, номер которого кратен 400, — високосный;
- остальные годы, номер которых кратен 100, — невисокосные (например, годы 1700, 1800, 1900, 2100, 2200, 2300);
- остальные годы, номер которых кратен 4, — високосные;
- все остальные годы — невисокосные.

Формат ввода
Вводится целое положительное четырёхзначное число — номер года.

Формат вывода
Программа выводит YES если год високосный и NO в противном случае.

Пример 1:
Ввод
2003

Вывод
NO

Пример 2:
Ввод
2004    

Вывод
YES
