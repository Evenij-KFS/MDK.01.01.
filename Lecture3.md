## Тема: Векторы и строки

`std::vector` и `std::string` — важные базовые контейнеры стандартной библиотеки C++. Они хранят свои элементы в непрерывном фрагменте памяти. Оба контейнера предоставляют доступ к элементам по индексу и позволяют эффективно добавлять новые элементы в конец.

## Контейнер `std::vector`

В стандартной библиотеке C++ вектором (`std::vector`) называется динамический массив, обеспечивающий быстрое добавление новых элементов в конец и меняющий свой размер при необходимости. Вектор гарантирует отсутствие утечек памяти.

Для работы с вектором нужно подключить заголовочный файл `<vector>`.

Он задаётся в угловых скобках после `std::vector`: например, `std::vector<int>` — это вектор целых чисел типа `int`, а `std::vector<std::string>` — вектор строк.

Само имя `std::vector` не является типом данных: это шаблон, в который требуется подставить нужные параметры — тип элемента, чтобы получился конкретный тип данных.

Рассмотрим пример программы, которая создаёт векторы разными способами:

```cpp
#include <string>
#include <vector>

int main() {
    std::vector<std::string> v1;              // пустой вектор строк
    std::vector<std::string> v2(5);           // вектор из пяти пустых строк
    std::vector<std::string> v3(5, "hello");  // вектор из пяти строк "hello"
}
```

Другой способ инициализации вектора — указать список элементов:

```cpp
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words = {"one", "two", "three"};
    std::vector<int> numbers = {1, 2, 3, 4, 5};
}
```

## Обращение к элементам

Для доступа к элементам вектора можно использовать индексацию. Индексация начинается с нуля:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    int a = data[0];  // начальный элемент вектора
    int b = data[4];  // последний элемент вектора, так как в нём пять элементов

    data[2] = -3;     // меняем элемент 3 на -3

    std::cout << a << ' ' << b << '\n';
}
```

По индексу элемента можно быстро найти его положение в памяти.

## Размер вектора

Чтобы узнать общее количество элементов в векторе, можно воспользоваться функцией `size`:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    std::cout << data.size() << "\n";
}
```

Отрицательные индексы, как в некоторых других языках программирования, не допускаются.

Обратите внимание: при обращении по индексу через квадратные скобки проверки корректности не происходит. Это проявление принципа «мы не должны платить за то, что не используем». Встроенные проверки замедляли бы программу: предполагается, что программист пишет правильный код и уверен, что индекс `i` в выражении `data[i]` неотрицателен и удовлетворяет условию `i < data.size()`.

Если обратиться к вектору по некорректному индексу, программа попадёт в неопределённое поведение: фактически она попробует прочитать память, не принадлежащую вектору.

Если в корректности индекса вы не уверены, можно использовать функцию `at`:

```cpp
#include <iostream>
#include <stdexcept>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    std::cout << data.at(0) << "\n";  // напечатается 1

    try {
        std::cout << data.at(42) << "\n";
    } catch (const std::out_of_range& e) {
        std::cerr << "out_of_range: " << e.what() << "\n";
    }
}
```

В случае `data.at(42)` произойдёт исключение `std::out_of_range`, его можно перехватить и обработать. Про работу с исключениями мы поговорим отдельно.

## `front` и `back`

Функции `front` и `back` возвращают первый и последний элемент без использования индексов:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    std::cout << data.front() << "\n";  // то же, что data[0]
    std::cout << data.back() << "\n";   // то же, что data[data.size() - 1]
}
```

Вызов этих функций на пустом векторе приведёт к неопределённому поведению.

## Проверка на пустоту

Для проверки вектора на пустоту вместо `data.size() == 0` принято использовать функцию `empty`:

```cpp
if (!data.empty()) {
    // вектор не пуст, с ним можно работать
}
```

## Итерация по индексам

В стандартной библиотеке индексы и размеры контейнеров имеют беззнаковый тип. Вместо `unsigned int` или `unsigned long int` используется псевдоним `size_t` (точнее, `std::vector<T>::size_type`). Тип `size_t` совпадает с `uint32_t` или `uint64_t` в зависимости от битности платформы.

Итерацию по элементам `data` с помощью индексов можно записать так:

```cpp
#include <cstddef>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    for (std::size_t i = 0; i != data.size(); ++i) {
        std::cout << data[i] << " ";
    }
}
```

Это каноническая форма: принято использовать сравнение `!=` и префиксный `++i`. Для целых чисел разницы нет, но для итераторов других контейнеров она появится. Давайте привыкнем оформлять цикл по индексам так.

Беззнаковость типа возвращаемого значения `size` порождает проблему. По правилам, унаследованным от C, результат арифметики над беззнаковым и знаковым типами приводится к беззнаковому. Поэтому выражение `data.size() - 1` тоже будет беззнаковым. Если `data.size()` окажется нулём, выражение будет не минус единицей, а самым большим беззнаковым целым.

Рассмотрим ошибочный код, проверяющий дубликаты подряд:

```cpp
// итерация по всем элементам, кроме последнего:
for (std::size_t i = 0; i < data.size() - 1; ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

На пустом векторе условие `i < data.size() - 1` окажется истинным, и произойдёт обращение к элементам пустого вектора. Правильнее переписать условие через `i + 1 < data.size()`:

```cpp
for (std::size_t i = 0; i + 1 < data.size(); ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

Или воспользоваться функцией `std::ssize` (C++20), возвращающей знаковый размер:

```cpp
#include <cstdint>
#include <iostream>
#include <iterator>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 2, 3};

    for (std::int64_t i = 0; i < std::ssize(data) - 1; ++i) {
        if (data[i] == data[i + 1]) {
            std::cout << "Duplicate value: " << data[i] << "\n";
        }
    }
}
```

## Добавление и удаление элементов

В вектор можно эффективно добавлять элементы в конец и удалять их с конца. Для этого существуют функции `push_back` и `pop_back`.

Рассмотрим программу, считывающую числа с клавиатуры в вектор и затем удаляющую все нули в конце:

```cpp
#include <iostream>
#include <vector>

int main() {
    int x;
    std::vector<int> data;

    while (std::cin >> x) {  // читаем числа, пока не закончится ввод
        data.push_back(x);   // добавляем очередное число в вектор
    }

    while (!data.empty() && data.back() == 0) {
        // Пока вектор не пуст и последний элемент равен нулю
        data.pop_back();  // удаляем этот нулевой элемент
    }

    for (int value : data) {
        std::cout << value << " ";
    }
}
```

Добавление и удаление в других частях вектора неэффективно, так как требует сдвига соседних элементов. Поэтому отдельных функций для добавления или удаления из начала у вектора нет. Это делается через общие функции `insert`/`erase` и итераторы, которые мы рассмотрим позже.

Удалить все элементы из вектора можно с помощью функции `clear`.

## Резерв памяти

Вектор хранит элементы в памяти в виде непрерывной последовательности. В конце резервируется дополнительное место для быстрого добавления новых элементов. Когда резерв заканчивается, при вставке очередного элемента происходит реаллокация: элементы копируются в новый, более просторный блок памяти.

Реаллокация — дорогая процедура, но если происходит редко, её влияние незначительно. Можно доказать, что если размер нового блока выбирать в два раза больше предыдущего, амортизационная сложность добавления элемента будет константной.

Текущий резерв вектора можно узнать с помощью функции `capacity` — не путайте с `size`.

Рассмотрим программу, в которой в вектор последовательно добавляются элементы и после каждого шага печатается размер и резерв:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2};
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(3);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(4);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(5);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
}
```

Вывод этой программы:

```text
2	2
3	4
4	4
5	8
```

Видно, что размер вектора увеличивается на единицу, а резерв удваивается после исчерпания. При добавлении четвёрки используется имеющаяся в резерве память, а при добавлении тройки и пятёрки происходит реаллокация.

Иногда требуется заполнить вектор элементами, причём число элементов известно заранее. Тогда можно сразу зарезервировать нужный размер памяти с помощью функции `reserve`, чтобы при добавлении элементов не происходили реаллокации:

```cpp
#include <cstddef>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words;

    std::size_t words_count;
    std::cin >> words_count;

    // Размер вектора остаётся нулевым, меняется только резерв:
    words.reserve(words_count);

    for (std::size_t i = 0; i != words_count; ++i) {
        std::string word;
        std::cin >> word;

        // Все добавления будут дешёвыми, без реаллокаций:
        words.push_back(word);
    }
}
```

Если передать в `reserve` величину меньше текущего резерва, резерв останется прежним.

Функцию `reserve` не следует путать с функцией `resize`, которая меняет количество элементов в векторе. Если аргумент `resize` меньше текущего размера, лишние элементы в конце удаляются. Если больше — при необходимости происходит реаллокация и в вектор добавляются новые элементы с дефолтным значением данного типа.

```cpp
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    data.reserve(10);  // поменяли резерв, но размер вектора остался равным пяти

    data.resize(3);    // удалили последние элементы 4 и 5
    data.resize(6);    // получили вектор 1, 2, 3, 0, 0, 0
}
```

## Многомерные векторы

Воспользуемся вектором векторов, чтобы сохранить матрицу целых чисел. Пусть на вход сначала поступают число строк и число столбцов матрицы, а потом — сами элементы построчно:

```cpp
#include <cstddef>
#include <iostream>
#include <vector>

int main() {
    std::size_t m, n;
    std::cin >> m >> n;  // число строк и столбцов

    // создаём матрицу matrix из m строк, каждая из которых — вектор из n нулей
    std::vector<std::vector<int>> matrix(m, std::vector<int>(n));

    for (std::size_t i = 0; i != m; ++i) {
        for (std::size_t j = 0; j != n; ++j) {
            std::cin >> matrix[i][j];
        }
    }

    // напечатаем матрицу, выводя элементы через табуляцию
    for (std::size_t i = 0; i != m; ++i) {
        for (std::size_t j = 0; j != n; ++j) {
            std::cout << matrix[i][j] << "\t";
        }
        std::cout << "\n";
    }
}
```

В этом примере мы заранее создали матрицу из нулей, а потом просто меняли её элементы.

## Сортировка вектора

Рассмотрим типичную задачу — отсортировать вектор по возрастанию. В заголовочном файле `<algorithm>` есть готовая функция `sort`. Гарантируется, что сложность её работы в худшем случае составляет `O(n log n)`, где `n` — число элементов. Типичные реализации используют алгоритм Introsort.

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    // Сортировка диапазона вектора от начала до конца
    std::sort(data.begin(), data.end());

    // получим вектор 1, 1, 2, 3, 4, 5, 6, 9
}
```

В функцию `sort` передаются итераторы, ограничивающие рассматриваемый диапазон. В нашем случае диапазон совпадает со всем вектором. Соответствующие итераторы возвращают функции `begin` и `end` — не путать с `front` и `back`. Итераторы можно считать обобщёнными индексами. Подробнее про итераторы мы поговорим в отдельном параграфе.

Для сортировки по убыванию можно передать обратные итераторы `rbegin()` и `rend()`:

```cpp
std::sort(data.rbegin(), data.rend());  // 9, 6, 5, 4, 3, 2, 1, 1
```

В C++20 доступен более элегантный способ через `std::ranges::sort`:

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    std::ranges::sort(data);  // можно передать сам вектор, а не его диапазоны
}
```

Для сортировки по умолчанию используется сравнение с помощью оператора `<`. Этот оператор работает и для самих векторов: они сравниваются лексикографически. Поэтому можно отсортировать, например, строки в матрице — векторе векторов целых чисел.

## Строки

Контейнер `std::string` можно рассматривать как особый случай вектора символов `std::vector<char>` с набором дополнительных функций. У строки есть все те же функции, что и у вектора, например `pop_back` или `resize`.

Рассмотрим специфические функции строки:

```cpp
#include <cstddef>
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string";

    // приписывание символов и строк
    s += ' ';          // добавляем отдельный символ в конец, это аналог push_back
    s += "functions";  // добавляем строку в конец
    std::cout << s << "\n";  // Some string functions

    // выделение подстроки
    // подстрока "string" из 6 символов начиная с 5-й позиции
    std::string sub1 = s.substr(5, 6);

    // подстрока "functions" с 12-й позиции и до конца
    std::string sub2 = s.substr(12);

    // поиск символа или подстроки
    std::size_t pos1 = s.find(' ');            // позиция первого пробела, в данном случае 4
    std::size_t pos2 = s.find(' ', pos1 + 1);  // позиция следующего пробела, 11
    std::size_t pos3 = s.find("str");          // вернётся 5
    std::size_t pos4 = s.find("#");            // вернётся std::string::npos

    std::cout << sub1 << "\n";
    std::cout << sub2 << "\n";
    std::cout << pos1 << ' ' << pos2 << ' ' << pos3 << "\n";

    if (pos4 == std::string::npos) {
        std::cout << "not found\n";
    }
}
```

Вставку, замену и удаление подстрок можно сделать через указание индекса начала и длины подстроки:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string functions";

    // вставка подстроки
    s.insert(5, "std::");
    std::cout << s << "\n";  // Some std::string functions

    // замена указанного диапазона на новую подстроку
    s.replace(0, 4, "Special");
    std::cout << s << "\n";  // Special std::string functions

    // удаление подстроки
    s.erase(8, 5);
    std::cout << s << "\n";  // Special string functions
}
```

Аналогичные действия для других контейнеров, например для вектора, можно сделать через итераторы. Мы рассмотрим такие примеры позже.

В C++20 появились функции `starts_with` и `ends_with` для проверки префикса или суффикса строк:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string phrase;
    std::getline(std::cin, phrase);

    if (phrase.starts_with("hello")) {
        std::cout << "Greeting\n";
    }

    if (phrase.ends_with("bye")) {
        std::cout << "Farewell\n";
    }
}
```

## Краткие итоги

- `std::vector` — динамический массив с непрерывным хранением элементов.
- `std::string` — удобная обёртка над последовательностью символов с большим набором строковых операций.
- Оба контейнера поддерживают индексацию, `size`, `empty`, `front`, `back`, `push_back`, `pop_back`, `resize`, `reserve`, `clear`.
- Для доступа с проверкой границ у вектора есть `at`.
- Для эффективной работы с заранее известным числом элементов используйте `reserve`.
- Для сортировки используйте `std::sort` или `std::ranges::sort`.
- Для строк доступны `substr`, `find`, `insert`, `replace`, `erase`, `starts_with`, `ends_with`.
